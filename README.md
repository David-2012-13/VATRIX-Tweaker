## ⚡ Overview

**VatrixTweaker** is a powerful, open-source system optimization utility built with Python (PySide6) designed to eliminate background telemetry, free up RAM instantly, and maximize your gaming and system performance on Windows 10 & 11.

---

## 🚀 Key Features

* **⚡ Flash RAM 1-Click:** Deep RAM cleanup and optimization instantly with a single click.
* **🛠️ Smart Debloat:** Remove unnecessary pre-installed Windows apps and bloatware safely.
* **🎮 Gaming Boost:** Reduce micro-stutters and background resource usage to stabilize your FPS.
* **🎨 Modern UI:** Sleek, fluid, and responsive interface designed with PySide6 in Dark Mode.
* **🔒 Privacy Control:** Disable aggressive Windows telemetry and tracking services.

---

## 💻 System Requirements

* **OS:** Windows 10 or Windows 11 (64-bit recommended)
* **Runtime:** Standalone executable (no external Python installation required for the compiled release)

---

## 📥 Download & Installation

1. Go to the [Releases](../../releases) tab.
2. Download the latest `VatrixTweaker.exe` file.
3. **Important:** Run the executable as **Administrator** to ensure all optimization scripts and system tweaks apply successfully.
