<h2>🚀 Despre VATRIXTweaker</h2>
<p>
    <strong>VATRIXTweaker</strong> este un utilitar open-source modern, rapid și eficient, conceput special pentru optimizarea, curățarea și debloat-ul sistemelor de operare <strong>Windows 10 și Windows 11</strong>. Scris în Python folosind interfața grafică PySide6 (Qt), programul îți oferă control complet asupra resurselor PC-ului tău.
</p>

<hr />

<h2>✨ Funcționalități Principale</h2>

<ul>
    <li><strong>⚡ Flash RAM 1-Click:</strong> Eliberare instantanee și optimizare profundă a memoriei RAM pentru un sistem mai rapid.</li>
    <li><strong>🛠️ Smart Debloat:</strong> Elimină în siguranță aplicațiile preinstalate inutile din Windows și procesele din fundal.</li>
    <li><strong>🎮 Gaming Boost:</strong> Reduce micro-stuttering-ul și oprește serviciile consumatoare pentru mai multe FPS-uri și stabilitate în jocuri.</li>
    <li><strong>🔒 Privacy Control:</strong> Dezactivează telemetria agresivă, serviciile de urmărire și colectarea de date de la Microsoft.</li>
    <li><strong>📊 Monitorizare în Timp Real:</strong> Vezi consumul de resurse, starea memoriei și detaliile hardware dintr-un singur panou curat.</li>
    <li><strong>🎨 Interfață Modernă UI:</strong> Design elegant în Dark/Light mode cu accent albastru și meniuri intuitive.</li>
</ul>

<hr />

<h2>💻 Cerințe de Sistem</h2>
<ul>
    <li><strong>Sistem de operare:</strong> Windows 10 sau Windows 11 (64-bit recomandat)</li>
    <li><strong>Rulare:</strong> Executabil autonom (nu necesită instalarea separată a Python)</li>
    <li><strong>Drepturi:</strong> Rulare cu drepturi de Administrator (pentru aplicarea optimizărilor de sistem)</li>
</ul>
