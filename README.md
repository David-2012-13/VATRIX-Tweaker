## 🚀 Despre Proiect

**VATRIXTweaker** este un utilitar ultra-rapid, open-source și complet transparent, dezvoltat în **Python (PySide6 / Qt)**. A fost creat special pentru a curăța bloatware-ul din Windows, a dezactiva telemetria invazivă și a elibera memoria RAM pentru o performanță maximă în jocuri și aplicații.

---

## ✨ Funcționalități Completes & Module

| Modul | Descriere & Acțiuni |
| :--- | :--- |
| **⚡ Flash RAM 1-Click** | Eliberare profundă a memoriei de lucru și optimizare instanță RAM. |
| **🛠️ Smart Debloat** | Eliminare sigură a aplicațiilor preinstalate inutile (UWP / Bloatware). |
| **🎮 Gaming & Performance Boost** | Reducerea micro-stuttering-ului, dezactivarea algoritmilor de throttling și optimizarea reducerii latentei. |
| **🔒 Privacy & Telemetry Killer** | Oprește colectarea de date Microsoft, serviciile de urmărire, Bing Search în Start și diagnosticările fundal. |
| **⚙️ Services & Startup Manager** | Control granular asupra serviciilor Windows (SysMain, Indexing, Print Spooler) și aplicațiilor din pornire auto. |
| **🌐 Winget Software Installer** | Instalator integrat rapid pentru cele mai populare aplicații și utilitare de sistem. |
| **📊 Real-Time System Monitor** | Monitorizează utilizarea resurselor (CPU, RAM, Temp), starea discurilor și specificațiile
