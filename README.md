## 🚀 Despre Proiect

**VATRIXTweaker** este un utilitar ușor, rapid și complet transparent, creat pentru a elimina telemetria agresivă din fundal, a elibera instantaneu memoria RAM și a maximiza performanța sistemului tău în jocuri și activități zilnice. 

Construit în **Python (PySide6 / Qt)**, oferă un design modern în Dark Mode cu gradient albastru și un panou de control intuitiv, fără reclame sau cod ascuns.

---

| Funcție | Descriere |

| **🛠️ Smart Debloat** | Elimină în siguranță aplicațiile preinstalate inutile și bloatware-ul
